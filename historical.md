# Historical and maintenance-mode inference engines

These projects are relevant to the design history or continued use of inference systems, but are not represented as actively maintained recommendations in the main [Awesome Inference Engines](README.md) index. Check their repository status, security, and dependencies before deployment.

- [ExLlamaV2](https://github.com/turboderp-org/exllamav2) - Earlier generation of the ExLlama quantized inference library and EXL2 checkpoint ecosystem; [ExLlamaV3](https://github.com/turboderp-org/exllamav3) is the current-generation project.
- [IPEX-LLM](https://github.com/intel/ipex-llm) - Intel-oriented optimized LLM execution project; the GitHub repository is archived.
- [raceline](https://github.com/audenvenn/raceline) - Apple Silicon-native engine for Qwen-family coding-agent workloads; the maintainer describes it as research/maintenance mode.
- [Text Generation Inference (TGI)](https://github.com/huggingface/text-generation-inference) - Hugging Face generation server whose repository is archived and whose README describes maintenance-only support.

Historical inclusion indicates relevance, not a claim that a project is unsafe or unsuitable for every existing deployment.
