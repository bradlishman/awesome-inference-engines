## Evidence boundaries

- **Upstream-documented:** The linked project claims the capability and provides code or documentation. This is what the matrix currently records.
- **Independently reproduced:** The same behavior has been run against a named release and artifact, with the hardware, command, output, and reproducible measurements disclosed. This requires an actual test, not a restatement of upstream numbers.
- **Comparable performance:** Requires identical model artifacts and workloads, plus reported latency, throughput, concurrency, cache state, memory budget, and correctness. Two measurements that change any of these conditions are not a controlled comparison.

There are **no independent performance rankings in this document**. A reproducible [local benchmark probe](bench/README.md) is available for collecting comparable measurements from engines that expose OpenAI-compatible streaming endpoints.
