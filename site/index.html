03 / EVIDENCE, NOT HYPE

A claim is not a benchmark.

Source provenance matters more than headline token rates. We keep documented capabilities separate from independently reproduced performance.

A

Upstream documented

A maintainer describes a supported model, platform, or optimization. The engine page links to that primary source.

B

Community reproduced

A user supplies an exact engine build, model artifact, hardware profile, and repeatable run receipt.

C

Independently measured

A controlled test reports comparable workloads, latency, throughput, and correctness with raw observations.
